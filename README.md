## Engineering Principles

- **Engineering before appearance:** interfaces should support a reliable and understandable technical workflow.
- **Explicit assumptions:** models, input data, units, and limitations should be identifiable.
- **Modular design:** keep application components understandable, testable, and maintainable.
- **Useful visualization:** 3D views should help users interpret engineering results rather than merely decorate the interface.
- **Incremental validation:** compare calculations and model behavior against suitable references before relying on results.
- **Practical integration:** connect data, analysis, visualization, and reporting into coherent workflows.
